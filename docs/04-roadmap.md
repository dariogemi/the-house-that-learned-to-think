# Roadmap

El roadmap no busca agregar tecnología por acumulación. Cada etapa debe aumentar comprensión, resiliencia o calidad de vida.

## Ahora — Consolidar la primera huella

- [ ] Completar la calibración visual V1.1 de `J.A.R.V.I.S. Engineering`.
- [ ] Confirmar origen, unidad y semántica de cada gauge.
- [ ] Implementar jerarquía nominal / warning / critical.
- [ ] Documentar rollback y evidencia del render final.
- [ ] Incorporar capturas sanitizadas de V1 y V1.1.

## Próximo — Memoria operativa

- [ ] Mantener un registro estructurado de intervenciones de Jarvis.
- [ ] Relacionar cambio, hipótesis, evidencia y resultado.
- [ ] Distinguir incidentes, mejoras, experimentos y decisiones.
- [ ] Evitar que el conocimiento quede enterrado en sesiones de chat.

## Después — Propuestas basadas en evidencia

- [ ] Detectar degradaciones persistentes, no solo picos.
- [ ] Proponer acciones con impacto, confianza y rollback.
- [ ] Comparar estado antes y después de una intervención.
- [ ] Aprender qué recomendaciones fueron aceptadas, rechazadas o revertidas.

## Futuro — El hogar como sistema colaborativo

- [ ] Modelar intención por ambiente, contexto y habitantes.
- [ ] Coordinar energía, clima, presencia y confort.
- [ ] Desarrollar interfaces que expliquen por qué actuó la casa.
- [ ] Permitir que distintos agentes colaboren con responsabilidades delimitadas.
- [ ] Preservar privacidad y ejecución local siempre que sea razonable.

## Pregunta guía

> ¿Este cambio hace que la casa sea más consciente del contexto o solamente más complicada?

Si no podemos responder con evidencia, todavía no está listo para entrar.
