# Recursos visuales

Subir en esta carpeta la imagen comercial principal con el nombre exacto:

`smart-home-ai-showcase.png`

La publicación `docs/06-tu-hogar-inteligente-asistido-por-ia.md` ya está configurada para mostrarla automáticamente mediante:

```markdown
![Tu hogar inteligente, asistido por IA](assets/smart-home-ai-showcase.png)
```

Formato recomendado:

- PNG
- orientación vertical
- ancho mínimo: 1200 px
- nombre en minúsculas, sin espacios

Cuando el archivo exista en esta ruta, GitHub lo mostrará en la cabecera del artículo sin necesidad de editar el Markdown.
